🆘 IF SOMETHING BREAKS

Logs:
   • GitHub Actions: https://github.com/montassar/barber/actions
   • Render Backend: https://dashboard.render.com
   • Vercel Frontend: https://vercel.com/dashboard
   • MongoDB: https://cloud.mongodb.com

Quick Fixes:
   1. Clear browser cache: Ctrl+Shift+R (or Cmd+Shift+R on Mac)
   2. Check Render logs for errors
   3. Verify MongoDB connection string
   4. Restart service: render restart --service-id [ID]
   5. Try deploying again: git push origin main

Common Issues:
   • Backend won't start? Check MongoDB connection
   • Frontend shows errors? Check VITE_API_BASE_URL
   • Can't login? Use: owner@barbershop.com / ChangeMe123!
